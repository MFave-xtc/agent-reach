MFave-xtc / agent-reach

Agent Reach auto-setup for Claude Code

This repository configures a SessionStart hook so that Claude Code on the web automatically installs and checks Agent Reach — an internet-access toolkit and router for AI agents — every time a session opens on this project.

How it works

On every session start, resume, or compact, Claude Code runs .claude/hooks/session-start.sh, which: 

1. Installs pipx (if missing)
2. Clones/installs Agent Reach via pipx (local clone, since the
   GitHub archive zip URL is blocked by this environment's proxy)
3. Installs yt-dlp
4. Runs the safe, read-only  agent-reach install --env=auto  check

System-level installs (--system) and any cookie-based channels (Twitter, Reddit, etc.) still require explicit approval each session — the hook never makes changes without asking.

Zero-config channels

  • Web pages — via Jina Reader (curl https://r.jina.ai/URL)
  • RSS / Atom feeds
  • YouTube — video info and transcripts (after --system install)
  • GitHub — repos and code (gh CLI, needs auth)
  • Semantic web search — via Exa (needs OAuth approval)

Files

.claude/hooks/session-start.sh   the hook script
.claude/settings.json            registers the SessionStart hook
